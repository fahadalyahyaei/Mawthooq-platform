# Mawthooq Platform

منصة رقمية للخدمات الأكاديمية في سلطنة عُمان.

## أهداف المنصة

- ربط طالبي الخدمات الأكاديمية بمقدمي الخدمات.
- تنظيم طلبات الخدمات الأكاديمية.
- توفير تجربة رقمية سهلة وآمنة.
## مراحل تطوير المشروع

المرحلة الأولى: إعداد المنصة
المرحلة الثانية: تسجيل المستخدمين
المرحلة الثالثة: مقدمو الخدمات
المرحلة الرابعة: الدفع الإلكتروني
المرحلة الخامسة: إطلاق المنصة
## نسخة التطوير

هذه إضافة تجريبية في فرع التطوير.
## الخدمات

- إعداد البحوث والتقارير
- المساعدة في الدراسات الأكاديمية
- التحليل الإحصائي
- الخدمات المرتبطة بالرسائل العلمية
